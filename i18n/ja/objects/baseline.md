# ベースライン

**What it is** — y = 0 タイプが座っている線と この地図の他の測定値の原点を引用します

**Status** — Live. Cited: フォントの座標原点; このマップのすべての y 値はそれに対して相対的です。

**Hits** — このグリフの内部には何もありません。これは参照であり、部分ではありません。それを移動すると、フォント全体の関係がそのメトリックに移動します。a ではありません。

**Does not hit** — 文字の下部。a は意図的にベースラインの下の −15 に達します。[overshoot](overshoot.md) を参照してください。
