# オーバーシュート

**What it is** — a は両端で自身のメトリックを破ります。頂点で 483 対 468 x-高さ、底部で −15 対 0 ベースライン。線を越えて 15 単位、上下。

**Status** — 残りは、正確な意味でこのマップが使う言葉です: 継承された修正はまだその役割を果たしており、取り除かれるべきではありません。引用: `sxHeight = 468`とベースライン0に対するグリフの境界 (23, −15, 556, 483)。

**Hits** — 文字の大きさです。丸い形や尖った形は、正確に平行線上に停止すると小さく見えます。パンチカッターがそれを通過させたのでしょう。オーバーシュートを取り除くと、a は n と x の隣に光学的に縮小します。

**Does not hit** — メトリクス自体です。ここには何も不整合はありません。これは、483 ≠ 468 を見て、丸め誤りを仮定したコールドリーダーによって「修正」される可能性が最も高いカードです。これは修正であり、欠陥ではありません。
