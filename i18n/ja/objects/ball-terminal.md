# ボール端子

**What it is** — 円形の仕上げ、左上。タイプグラフィックの基本スキルの用語集では、ボール端子は「ロマンティック時代の多くの表面」に位置づけられています。スキル自身の分類参考書では、Clarendon は Slab Serif / Egyptian / Antique の下にリストされていますが、その系統ではありません。つまり、この装飾的な装置は Clarendon 自身のカテゴリに属するものではなく、借りたものです。他の伝統の宝飾品を着用した Slab Serif です。

**Status** — 外側等高線歩行，点２５０〜４５０，半径５８単位近くの（１１７，３４２）点を中心とする近円を描く。

**Hits** — 下の開口部はボールが大きくなり、開口部が狭くなる。また、表面の時代同一性も、これを正方形にすると、Clarendonは1世紀若く見える。

**Does not hit** — カウンター。カウンターはボウルとステムに囲まれ、ボール端子はそれに触れません。[counter](counter.md)を参照してください。
