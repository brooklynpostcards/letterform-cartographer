# ステム

**What it is** — 主な垂直方向、右側、刺が基線から離れるところから先端が取って代わるところまで。文字の全幅ではありません。茎のインクは、高さの中央で約 x=302–440 に広がります（より上では少し狭くなります）。x=556, にある文字の右端は、茎ではなく刺の別々のカールに属します。

**Status** — ライブ。引用：y=210の実際の輪郭の点在ポリゴンスキャンでは、x=324–440を横切るインクしか見つからない（このカードの初稿では、ステムがx=556に達すると間違って記載されていたが、実際の轮郭と再確認した後に訂正された。`reference/decisions.md`を参照）。

**Hits** — ボウルとカウンターの幅に対してストロークをコントラストさせる。ステムの左端がカウンター右壁でもあるからである。ステムを厚くすると、カウンターは狭くなる。

**Does not hit** — The glyph's set width. That's set by the spur's own rightward curl, a separate stroke the stem doesn't touch — see [spur](spur.md). Also does not hit the x-height, a font-wide vertical metric applied to every lowercase glyph; you cannot change it from inside this letter. See [x-height](x-height.md).
