# 球端子

**What it is** — 圆形的结尾处,左上角。 印刷基本技能的词汇表将球形端子放在“许多浪漫时期的面孔 ” ; 技能本身的分类参考列出Clarendon在Slab Serif / Egyptian / Antique下,而不是那个系谱 — — 所以这是一个装饰装置ZQX1借来的,而不是一个本土的它自己的类别。

**Status** — 引用:外部等高线行走,点250-450,追踪一个中心在(117,342)的近圆,半径接近58个单位。

**Hits** — 下面的孔径:球增长,开口缩小。 还有面部的时代身份,因为平方这使得Clarendon读一个世纪年轻。

**Does not hit** — The counter. The counter is enclosed by the bowl and the stem; the ball terminal never touches it. See [counter](counter.md).
