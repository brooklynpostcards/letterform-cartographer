# 菲尼亚尔

**What it is** — 装饰性的终端笔划,从字体顶部开始,在x高度上升,然后从左侧向下延伸到[ball terminal](ball-terminal.md)。 排版基础技能词汇表中,这个术语专门用于*a*和*f* — — 一般的“弧 ” ( 用于*n*、*m*、*h*)是不同字母形状上的不同部分;参见[naming-collisions](../reference/naming-collisions.md)。

**Status** — 引用:外等高线行走,点125-250,跑(441,350)到(292,481)到(49,343 ) 。

**Hits** — 整个小写字母的表面x高度,因为它的顶部带有使圆形字母与平面字母匹配的过度。 还有它构成顶部的孔径。

**Does not hit** — 肩膀。 肩膀属于 *n *, *m *, 和 *h * — 离开一个支柱,回到基线上的一个脚。 这一个结束在一个终点,永远不会返回基线,所以它不是一个肩膀,它不是一个拱;它是一个终点。
