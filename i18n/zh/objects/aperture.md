# 光圈

**What it is** — 左边的开口,在球端子的下面和碗的外边缘之间。 字母呼吸的空隙。

**Status** — 引用:上部由球端的下边缘在(115,285)附近界定,顶部由终端覆盖,下部由碗的内部扫描通过(151,247)到(24,130 ) 。

有一点值得明确指出:印刷基础技能中关于 *a* 上的孔径的实例(`counterform-notes.md`)描述了单层无衬线体形式,其中孔径是同一个部分开放的计数器的一部分。 这是一个双层 *a*,有一个完全封闭的计数表 — — 一个完全独立的轮廓(参见 [counter](counter.md) ) 。 这里命名的间隙是真实的,并且实际上与该计数器无关,但称之为“孔径”扩展了技能中的单层例子,而不是直接引用一个双层例子。

**Hits** — 小尺寸的可读性。 闭合的光圈是将屏幕上a变成o的第一件事,也就是道路标志或脚注。

**Does not hit** — 计数器。 关闭孔径并不会使计数器缩小;它们是两个带有独立边界的白色形状。 这与 [counter](counter.md) 中从另一侧描述的碰撞是相同的。
