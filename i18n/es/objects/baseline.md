# Base de referencia

**What it is** — y = 0 La línea en la que se encuentra el tipo, y el origen desde el que se cita cada otra medida en este mapa.

**Status** — Citado: el origen de las coordenadas de la fuente; cada valor de y en este mapa es relativo a él.

**Hits** — Nada dentro de este glifo, es la referencia, no una parte. Al moverlo se mueve toda la relación de la fuente con sus propias métricas, no la a.

**Does not hit** — The bottom of the letter. The a reaches −15, below the baseline, on purpose. See [overshoot](overshoot.md).
