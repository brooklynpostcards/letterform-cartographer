## Walk order

1. Read the catalog table at the top of `examples.md`. Eleven rows, one glyph.
2. If the question names a specific part, open exactly the one matching card in `objects/`. Stop there.
3. Only open `reference/naming-collisions.md` if the part's own card flags a collision relevant to your question.
4. On the live site (`docs/index.html`), this is enforced mechanically: hovering one region of the letter fetches and renders exactly one card from `objects/` — never all eleven, never the whole folder.

If a question spans two parts ("what's the difference between the counter and the aperture"), that's two card reads — open both named cards, nothing else in the folder.
